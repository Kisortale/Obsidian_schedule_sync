# Расписание из Google Таблицы → Obsidian
Программа берёт расписание вашей группы из Google Таблицы, раскладывает его по дням в виде
`.md`-заметок в хранилище Obsidian, раз в N минут проверяет таблицу и присылает уведомление,
если что-то изменилось (добавили/убрали пару, поменяли аудиторию, время, преподавателя, отмена).
## Запуск
Нужен Python 3.9+ (на Windows и macOS tkinter уже входит в установщик; на Linux: `sudo apt install python3-tk`).
```
pip install -r requirements.txt     # необязательно:  системные уведомления (plyer)
python run.py                       # открывает окно
```
### В окне:
Добавить профиль (у каждого пользователя свой: группа + своя папка Obsidian).
Вставить ссылку на таблицу, нажать Загрузить группы, выбрать свою группу.
Выбрать папку хранилища Obsidian (vault).
Сохранить профиль → Обновить сейчас → Запустить автообновление.
Таблица должна быть открыта по ссылке: «Все, у кого есть ссылка — Читатель».
### Без окна (командная строка)
```
python run.py groups
python run.py add --name Я --group 26КНТ-1 --vault "D:/Obsidian/Моё"
python run.py sync                  # один раз
python run.py daemon --interval 30  # в фоне, каждые 30 минут
```
Данные программы лежат в `\\\~/.schedule\\\_sync` (настройки и снимки расписания для сравнения);
папку можно сменить переменной окружения `SCHEDULE\\\_SYNC\\\_HOME`.
## Что появляется в Obsidian
```
Расписание/
  Расписание.md      # ближайшие 7 дней (встраивает заметки дней)
  Изменения.md       # журнал изменений с датой обновления
  2026-10-19.md      # по файлу на каждый день
```
Сгенерированная часть заметки дня обрамлена маркерами `<!-- schedule-sync:start/end -->`.
Всё, что вы допишете вне маркеров (конспект, домашка), при обновлении сохраняется.
Файл перезаписывается только если содержимое реально изменилось.
## Как разбирается таблица
строка с группами находится по шаблону `26КНТ-1`; список групп для выбора берётся из неё;
для каждой группы три колонки: занятие | Ауд. | Корпус;
«День» заполнен только в первой строке дня, «Время» задаёт слот пары;
в ячейке может быть несколько занятий; их делит фамилия преподавателя (`Иванов И.И.` / `Вакансия`);
перед занятием поддерживаются даты: `07.09., 21.09.`, `07.09.-19.10.` (каждую неделю), `с 09.09.`,
опечатки вроде `05.10.. 19.10.`; без даты — каждую неделю в пределах модуля
(период берётся из заголовка «(01.09. - 25.10.)»);
пометки `06.10. в 09:30-10:10` (изменено время) и `11.09. - отмена занятия`;
аудитории и корпуса сопоставляются с занятиями по порядку; одно значение относится ко всем;
`online` и код онлайн-курса (`26\\\_27\\\_М\\\_ОРГ\\\_Г\\\_...`) распознаются отдельно;
всё, что не удалось разобрать, пишется в журнал как предупреждение (⚠), а не ломает обновление.
## Структура проекта
```
run.py                    точка входа
schedule\\\_sync/parser.py   разбор таблицы
schedule\\\_sync/fetcher.py  загрузка CSV из Google Sheets
schedule\\\_sync/obsidian.py запись заметок
schedule\\\_sync/differ.py   сравнение версий и текст уведомлений
schedule\\\_sync/service.py  синхронизация профилей и планировщик
schedule\\\_sync/gui.py      окно (tkinter)
tests/                    python -m unittest discover -s tests
```
## Ограничения
Уведомления приходят (если подключены), пока программа запущена (окно или `daemon`). Для push на телефон
понадобится отдельный сервер или Telegram-бот.
Читается CSV-экспорт одной вкладки (`gid` из ссылки). Для нового модуля нужно поменять её в профиле; формат шапки парсер переживёт, если сохранится схема «группа | Ауд. | Корпус».
Если вертикально объединённые ячейки в таблице реально объединены, Google отдаёт в CSV текст
только в первой строке объединения — тогда «сдвоенная» пара будет считаться одной.
